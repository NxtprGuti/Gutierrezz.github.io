METODOS NUMERICOS

Herramienta académica para importar datos experimentales, aplicar métodos numéricos y analizar resultados mediante tablas y representaciones gráficas.

Importación de datos

Selecciona un archivo CSV o Excel que contenga tus mediciones. Los datos se utilizarán como entrada para los cálculos.

Selecciona tu archivo de datos

Esperando un archivo CSV o Excel.

Área de trabajo

Selecciona las columnas que representarán las variables independientes (x) y dependientes (y). Los datos se validarán antes de utilizarlos en los métodos numéricos.

Esperando datos.

Primero carga un archivo CSV o Excel en la sección anterior. Aquí aparecerán la selección de variables y la tabla de datos.

Métodos de interpolación

Selecciona las columnas x e y en el área de trabajo y calcula una estimación mediante el método de interpolación de Lagrange.

Interpolación de Lagrange

Introduce el valor de x en el que deseas estimar y. Se utilizarán todos los puntos válidos de las columnas elegidas.

Interpolación de Newton por diferencias divididas

Se utilizarán los mismos datos cargados y las columnas x e y seleccionadas para construir la tabla de diferencias divididas, obtener el polinomio interpolante y estimar el valor de y.

Interpolación por el método matricial

Se construirá la matriz de Vandermonde y se calcularán los coeficientes del polinomio interpolante mediante la matriz inversa.

Interpolación por splines cúbicos naturales

Se construirán polinomios cúbicos por tramos para interpolar los datos seleccionados.
